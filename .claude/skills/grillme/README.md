# grillme

Skill de proyecto instalada localmente porque `/plugin` no está disponible en este entorno de Claude Code on the web.

Fuente original: [Jekudy/grillme-skill](https://github.com/Jekudy/grillme-skill) (MIT). El contenido de `SKILL.md` es una copia fiel del `SKILL.md` original del plugin, colocada como skill de proyecto en `.claude/skills/grillme/` para que Claude Code la detecte automáticamente en este repositorio.

## Uso

Invócala diciendo "grill me", "grillame", "ásame a preguntas", o los disparadores originales en ruso ("задавай вопросы", "допроси меня", "интервью").

## Si luego tienes acceso al CLI local de Claude Code

Puedes instalar el plugin oficial en su lugar:

```bash
claude marketplace add https://github.com/Jekudy/grillme-skill.git
claude plugin install "grillme@grillme-marketplace"
```
